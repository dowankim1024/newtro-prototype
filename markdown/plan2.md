# 그날의 트랙 (Track of the Day)

---

## 1. 제품 한 줄 정의

**"뻔한 90년대 탑100 플레이리스트에 지친 당신을 위한, 초개인화 레트로 음악 매거진 & 프라이빗 토론 라운지"**

---

## 2. 타겟 고객 및 문제 정의

- **Core Target:** 과거의 음악을 즐겨 듣지만, 유튜브나 멜론의 '2000년대 댄스 모음집' 같은 양산형 플레이리스트로는 자신의 섬세한 취향을 채우지 못하는 3040 세대.
- **User Problem:**
  - "내가 진짜 좋아했던 건 타이틀곡이 아니라 3번 트랙 수록곡인데, 알고리즘은 맨날 뻔한 타이틀곡만 추천해 줘서 아쉽다."
  - 내가 들었던 과거의 노래가 있었는데 기억이 잘 안난다.
  - "이 노래에 얽힌 내 감성과 썰을 풀고 싶은데, 일반 유튜브 댓글창은 너무 어리고 산만하다."
- **Solution:** 매일 발행되는 '과거의 오늘' 음악 매거진을 통해 잊고 있던 명곡을 디깅(Digging)하게 돕고, 이를 실제 내 플레이리스트로 직배송해 주며, 동년배들과 심도 있게 대화할 수 있는 프리미엄 공간을 제공.

---

## 3. 핵심 기능 (Core Features)

### 3.1. 데일리 뮤직 매거진: <오늘의 디깅>

- **기능:** 매일 아침, 과거 특정 연도의 오늘 날짜에 얽힌 음악적 서사를 매거진 형태로 발행. (예: "1999년 오늘, 가요계를 휩쓴 테크노 열풍 속에서 조용히 빛났던 발라드 3선")
- **UX:** 스크롤에 따라 당시의 앨범 커버와 짧은 아티클이 교차하며 등장. 텍스트를 읽는 동안 배경음악으로 해당 곡이 1분간 재생됨.
- **인터랙션:** 매거진을 읽으며 마음에 드는 곡의 '디스켓' 아이콘을 누르면 내 보관함에 즉시 담김.

### 3.2. 취향 수집 & 인앱 플레이리스트: <나의 믹스테이프>

- **기능:** 매거진에서 수집한 곡들이 나만의 플레이리스트로 쌓이는 공간.
- **시각화:** 리스트업 형태가 아닌, 수집한 곡의 시대/장르에 따라 **카세트테이프, CD, LP** 등의 3D 디지털 오브젝트 형태로 렌더링되어 소유의 쾌감을 극대화.

### 3.3. UGC 유저 매거진: <내 기억 속 그 트랙>

- **기능:** 프리미엄 유저가 자신만의 작은 매거진을 직접 발행할 수 있는 공간.
- **작성 방식:** 제목(예: "2003년 내가 학원 끝나고 버스 안에서 MP3로 듣던 노래들"), 3~5곡 선곡, 짧은 에피소드(200자 내외)를 묶어 하나의 매거진으로 발행.
- **UX:** 발행된 유저 매거진은 <오늘의 디깅> 하단의 '이웃의 믹스테이프' 섹션에 피드 형태로 노출. 일반 유저는 열람 및 곡 수집 가능, 작성/발행은 프리미엄 전용.
- **보상:** 발행 시 프로필에 '테이프 마스터' 뱃지 부여. 월간 우수 매거진 선정 시 공식 푸시 알림으로 전 유저에게 소개.
- **효과:**
  - **사용자 관점:** 자신의 추억이 큐레이션되어 타인과 공유되는 정서적 보상. 수동적 소비자를 능동적 창작자로 전환.
  - **서비스 관점:** 콘텐츠 공급 비용(큐레이터 인건비) 절감, 유저 간 신뢰도 높은 추억 콘텐츠 축적, 커뮤니티 활성화.
  - **BM 관점:** UGC 작성 권한이 프리미엄 전환의 강력한 동기로 작용.
  - **데이터 관점:** 유저가 직접 작성한 시대·장소·감정 맥락 데이터가 축적되어 AI 추천 정밀도 향상의 원재료가 됨.

### 3.4. AI 타임캡슐 믹스: <나만의 숨은 트랙>

- **기능:** 프리미엄 유저 전용. 출생연도, 졸업연도, 좋아했던 장르 태그 3개를 입력하면 AI가 그 시기 발매된 숨은 수록곡들로 **주 1회 개인 맞춤형 매거진** 자동 생성.
- **피드백 루프:** 추천된 곡을 몇 개 수집했는지에 따라 다음 주 추천 알고리즘이 점점 정교해짐.
- **차별화 포인트:** "뻔한 탑100"과의 결정적 단절. 사용자가 몰랐던, 혹은 잊고 있던 '3번 트랙 수록곡'을 발굴해 주는 초개인화 엔진.
- **효과:**
  - **사용자 관점:** "이 노래를 어떻게 알았지?" 하는 놀라움과 발견의 기쁨. 나만의 취향이 진정으로 이해받는 경험.
  - **BM 관점:** 프리미엄 구독의 핵심 리텐션 축. 매주 새로운 콘텐츠가 도착하므로 이탈 방어에 강력함.
  - **데이터 관점:** 사용자의 수집/스킵 행동 데이터가 '감정-시대-장르' 메타 태그와 결합되어 AI 모델의 지속적 고도화.

### 3.5. 레트로 음악 토론장: <리플레이 라운지>

- **기능:** 앱에서 던져주는 시대별 음악 주제에 대해 동년배들과 교감하는 공간.
- **무료 투표 (Free):** "2005년 SG워너비 vs 2005년 버즈, 당신의 MP3를 지배했던 목소리는?" 같은 직관적인 A/B 투표에 참여하고 실시간 비율 확인 가능.
- **유료 코멘트 (Premium):** 단순 투표를 넘어, 내 의견을 글로 남기고 타인의 의견에 대댓글을 달며 깊은 썰을 푸는 기능. (댓글창 자체를 '클린하고 수준 높은 프라이빗 살롱'으로 브랜딩)

## 4. 수익 모델 (Business Model: Freemium)

초기 사용자 모집 : 인스타그램과 함께 운영(명곡 디깅 게시물 → 앱 내 매거진 페이지로 다이렉트 연결)

앱의 트래픽을 모으는 기능은 무료로, 유저의 '귀찮음'을 해결하거나 '지적 허영심/소통 욕구'를 채우는 기능은 철저히 유료로 분리합니다.

| **구분**         | **무료 플랜 (Free)**                       | **프리미엄 플랜 (Premium / 월 4,900원)**                                                                       |
| ---------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| **콘텐츠 소비**  | 매일 발행되는 매거진 열람, 1분 미리듣기    | 전체 매거진 무제한 지난보기 (아카이브 접근)                                                                    |
| **플레이리스트** | 앱 내 보관함(믹스테이프)에 곡 수집 및 저장 | **[핵심 BM]** 터치 한 번으로 내 유튜브 뮤직/스포티파이 재생목록으로 곡 리스트 100% 자동 전송 (Export API 연동) |
| **개인화**       | 기본 태그 기반 장르 추천                   | **[핵심 BM]** AI 타임캡슐 믹스 주 1회 발행 (초개인화 숨은 명곡 추천)                                           |
| **UGC**          | 유저 매거진 열람 및 곡 수집                | **[핵심 BM]** 나만의 매거진 작성/발행 권한, '테이프 마스터' 뱃지 획득                                          |
| **토론장 참여**  | 라운지 주제 확인 및 A/B 버튼 투표 참여     | **[핵심 BM]** 라운지에 내 썰(의견) 작성, 타인 글에 공감/댓글 작성 권한 부여 (프리미엄 뱃지 노출)               |

## 5. 기술 및 UX 구현 전략

- **프론트엔드 최적화 (Next.js):** PWA로 구축하여 앱 설치 허들을 낮추면서도, 모바일 브라우저에서 네이티브 앱 수준의 매끄러운 페이지 전환(SPA)을 구현.
- **인터랙티브 렌더링 (WebGL/Three.js):** 유저가 모은 '나의 믹스테이프' 공간에 들어갔을 때, 평면적인 앨범 아트를 보여주는 대신 WebGL을 활용해 카세트테이프나 턴테이블이 실제 돌아가는 듯한 3D 시각 효과를 부여. 빛 반사와 질감 표현으로 '실제 굿즈를 소유한 느낌'을 전달.
- **외부 음악 API 연동:** OAuth 인증을 통해 YouTube Data API v3 및 Spotify Web API를 연동하여, 유저가 수집한 곡의 ID를 매칭해 클릭 한 번에 실제 스트리밍 앱의 플레이리스트로 밀어 넣는 파이프라인 구축.
- **AI 추천 엔진:** 사용자의 수집 행동, UGC 매거진 작성 맥락(시대·장소·감정 키워드), 라운지 댓글 자연어 분석 데이터를 결합한 협업 필터링 + 콘텐츠 기반 필터링 하이브리드 모델. 초기 콜드 스타트는 큐레이터 수동 태깅으로 보완.
